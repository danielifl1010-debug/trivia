# משחק טריוויה – גרסה 2

משחק טריוויה בזמן אמת: המנחה מציג שאלות על מסך, והמשתתפים עונים מהטלפון (בדפדפן).

## מה יש במערכת

- **עורך חידונים** עם שמירה אוטומטית בשרת, שכפול, הזזה ומחיקה של שאלות, ייצוא וייבוא
- **יצירת שאלות ב-AI** (Gemini, Groq ו-OpenRouter): כותבים נושא ובוחרים כמות ורמת קושי. השאלות נכנסות לעורך מסומנות "לבדוק". אם שירות אחד עמוס, המערכת עוברת לבא בתור
- **תמונות**: אפשר להעלות מהמחשב (התמונה מכווצת אוטומטית) או להדביק קישור
- **סיסמת מנחה**: רק מי שיודע את הסיסמה יכול לערוך ולנהל
- **מסך לובי** עם קוד בן 4 ספרות וקוד QR לסריקה
- **ניקוד לפי מהירות** (500–1000 לתשובה נכונה), גרף תשובות וטבלת מובילים אחרי כל שאלה, ופודיום בסיום
- **דוח תוצאות** להורדה, נפתח ב-Excel: לכל משתתף ניקוד ומה ענה בכל שאלה
- **שליטה במקלדת או בשלט מצגות**: רווח, Enter או PageDown עוברים לשלב הבא, F למסך מלא
- **עמידות לניתוקים**: מי שמרענן או שהמסך שלו ננעל חוזר למשחק עם הניקוד שלו. המערכת מחכה לו 4 שניות לפני שהיא מציגה את התשובה
- **הגנות**: אי אפשר לשנות תשובה, לענות אחרי הזמן, להתחזות למנחה או להזריק קוד דרך שמות
- נבדק עם 60 משתתפים בו-זמנית. התקרה היא 120 משתתפים למשחק

## העלאה לאינטרנט בחינם

### שלב 1: מסד נתונים חינמי (כדי שהחידונים לא יימחקו)
בשרת החינמי של Render הקבצים נמחקים בכל הפעלה מחדש, ולכן החידונים נשמרים ב-MongoDB Atlas (חינם לצמיתות):
1. נרשמים ב-mongodb.com/atlas ← Create ← בוחרים **M0 Free**
2. Database Access ← יוצרים משתמש וסיסמה
3. Network Access ← Add IP Address ← **Allow access from anywhere** (0.0.0.0/0)
4. Connect ← Drivers ← מעתיקים את הכתובת (מתחילה ב-`mongodb+srv://`) ומחליפים בה את `<password>` בסיסמה שיצרתם

### שלב 2: מפתחות AI (ליצירת שאלות, לא חובה)
מומלץ להגדיר את שניהם: אם אחד עמוס, המערכת עוברת לשני לבד. שניהם חינמיים ובלי כרטיס אשראי.
- **Gemini:** נכנסים ל-aistudio.google.com, לוחצים Get API key ואז Create API key
- **Groq (גיבוי, מהיר מאוד):** נרשמים ב-console.groq.com, לוחצים API Keys ואז Create API Key
- **OpenRouter (גיבוי נוסף):** נרשמים ב-openrouter.ai, נכנסים ל-Keys ולוחצים Create Key. משתמשים במודלים החינמיים בלבד, בלי חיוב

### שלב 3: השרת (Render)
1. מעלים את התיקייה למאגר ב-GitHub
2. ב-render.com ← New ← **Blueprint** ← בוחרים את המאגר. הקובץ `render.yaml` מגדיר הכול לבד
3. Render יבקש למלא:
   - `ADMIN_PASSWORD`: סיסמת המנחה שתבחרו
   - `MONGODB_URI`: הכתובת משלב 1
   - `GEMINI_API_KEY`: המפתח של Gemini משלב 2 (אפשר להשאיר ריק)
   - `GROQ_API_KEY`: המפתח של Groq משלב 2 (אפשר להשאיר ריק)
   - `OPENROUTER_API_KEY`: המפתח של OpenRouter משלב 2 (אפשר להשאיר ריק)
4. אחרי כמה דקות תקבלו כתובת כמו `https://trivia-xxxx.onrender.com`

**חשוב:** בחבילה החינמית השרת "נרדם" אחרי רבע שעה בלי שימוש, וההתעוררות לוקחת כדקה. פתחו את דף המנחה כמה דקות לפני האירוע. בזמן משחק הוא לא נרדם.

## הרצה על המחשב (לבדיקה או לאירוע ברשת מקומית)

```
npm install
npm start
```
- מנחה: `http://localhost:3000/host`. בלי סיסמה, החידונים נשמרים בתיקייה `data`
- משתתפים באותה רשת Wi-Fi: `http://<כתובת-המחשב>:3000/play`. את כתובת המחשב מוצאים בפקודה `ipconfig`, בשורה IPv4

כדי להגדיר סיסמה או מפתח AI גם במחשב (בווינדוס, PowerShell):
```
$env:ADMIN_PASSWORD="1234"; $env:GEMINI_API_KEY="..."; npm start
```

## הגדרות (משתני סביבה)

| משתנה | מה עושה | חובה? |
|---|---|---|
| `ADMIN_PASSWORD` | סיסמת המנחה | מומלץ מאוד בשרת |
| `MONGODB_URI` | חיבור ל-MongoDB לשמירה קבועה | בשרת חינמי: כן |
| `GEMINI_API_KEY` | יצירת שאלות ב-AI עם Gemini | לא |
| `GROQ_API_KEY` | יצירת שאלות ב-AI עם Groq (גיבוי ל-Gemini, או לבד) | לא |
| `OPENROUTER_API_KEY` | יצירת שאלות ב-AI עם המודלים החינמיים של OpenRouter | לא |
| `AI_PREFER` | `groq` או `openrouter`: איזה שירות לנסות ראשון | לא |
| `GEMINI_MODEL` | מודל Gemini אחר (ברירת מחדל: `gemini-3.5-flash`, ואם הוא לא קיים המערכת מנסה מודלים חלופיים) | לא |
| `PORT` | פורט השרת (ברירת מחדל 3000) | לא |
